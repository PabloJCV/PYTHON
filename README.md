# Calculadora de Salario en Python

Este proyecto es una calculadora sencilla desarrollada en Python que permite calcular el salario bruto y el salario neto de un empleado, aplicando un rebajo del **10.83%** correspondiente a las cargas sociales del trabajador.

## Características

- Solicita el nombre del empleado.
- Solicita las horas laboradas.
- Solicita el monto por hora.
- Calcula el salario bruto.
- Calcula el rebajo del 10.83%.
- Muestra el salario neto.


## Objetivo

Este proyecto fue desarrollado como práctica para reforzar conceptos básicos de Python, incluyendo:

- Variables
- Entrada de datos (`input`)
- Conversión de tipos (`float`)
- Operaciones matemáticas
- Cálculo de porcentajes
- Formato de salida con `f-strings`
